How these were obtained
--------------------------------------------------------------------------
Both source archives are large (103MB / 802MB) crowdsourced-recording ZIPs.
Rather than downloading either archive in full, only the 6 needed WAV
entries were fetched via HTTP range requests against each ZIP's central
directory (standard ZIP random-access technique: fetch the End-Of-Central-
Directory record, then the central directory itself, to get each target
entry's exact byte offset and compressed size, then range-fetch only that
entry) - ~2.4MB of HTTP transfer total against ~900MB of archives. Each
extracted file's CRC-32 was verified against the ZIP's own recorded CRC
before use.

Original files are 48kHz mono 16-bit PCM WAV (studio-quality crowdsourced
recordings, not phone-mic quality). RealSpeechCorpus.kt resamples these to
16kHz mono at load time using the same linear resampler
(com.retroid.translator.audio.AudioResample) that the synthetic eSpeak-TTS
test clips already used, so the two test-audio sources go through identical
resampling code before reaching Vosk.

CC BY-SA 4.0 requires attribution + share-alike for redistribution of these
specific audio files. They are bundled here for offline on-device dual-
recognizer validation testing (docs/specs/fold5-adaptation.md §4), not
resold or repackaged as a voice/TTS product.
